# Textures

Tiling 128×128 PNGs, mostly white with faint grain, laid over a plain background colour.

- `canvas.png`: an even grid of fine dots, like canvas weave
- `paper.png`: scattered speckle, like paper
- `linen.png`: soft sideways streaks, like linen

Use: `background-image: url('/textures/paper.png'); background-repeat: repeat;`

Not used on any screen yet; a later feature will let people pick one. All three show on the design page (`/design` while developing).
